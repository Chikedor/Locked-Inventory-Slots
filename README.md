# Locked Inventory Slots

Work in progress for Fields of Mistria 1.0.3. The current research build validates the safety-critical Sort integration with inventory slots 1, 2, and 3 locked for diagnostics. Player-facing lock controls, persistence, and UI will be added only after the sorting transaction is proven safe.

## Development requirements

- Fields of Mistria 1.0.3, Steam build 24742087
- MOMI/MMAPI 0.15.5

This repository is not yet a player release.
